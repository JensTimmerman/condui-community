Place the starter example ZIP in this folder as:

- `starter-project.zip`

How to create it:

1. Build the project template in the app.
2. Use "Download project" from the home card menu.
3. Rename the exported file to `starter-project.zip`.
4. Put it in `apps/app/public/examples/`.

Runtime behavior:

- The example card is shown when there are no saved projects.
- Clicking "Open example project" imports this ZIP to local storage and opens it.
- If the user never clicks it, nothing is imported.
